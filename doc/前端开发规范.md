# zt-abroad-uniapp C 端开发规范

> 适用：学生、家长使用的 C 端（H5、微信小程序）。管理后台规范见 `../zt-abroad-vue/doc/前端开发规范.md`，后端规范见 `../zt-abroad-parent/doc/开发规范.md`（第 14.6 节「管理端与 C 端分离」）。
> 版本：v1.0（2026-10-15，M1-06）

## 1. 技术栈

| 项 | 选型 |
| --- | --- |
| 框架 | uni-app（Vue 3，`<script setup>`），CLI 工程（不依赖 HBuilderX） |
| 构建 | Vite 5；`npm run build:h5`、`npm run build:mp-weixin`，产物在 `dist/build/<端>/` |
| 样式 | SCSS（`sass`）；全局变量在 `src/uni.scss`；尺寸用 `rpx` |
| 测试 | `node --test`（`test/`），只测与 uni 运行时无关的逻辑 |

## 2. 目录

```
src/
├── App.vue            启动：记录渠道码、预取访客令牌
├── main.js
├── manifest.json      H5 路由为 history 模式（Nginx 需 try_files 回退到 index.html）
├── pages.json         页面路由
├── uni.scss           全局样式变量
├── api/               接口：按资源分文件，全部经 request.js
├── pages/<模块>/<页面>.vue
├── static/            静态资源
└── utils/             client.js（请求核心）、channel.js（渠道码）、env.js（端与后端地址）、storage.js（本地存储）
```

## 3. 接口调用

- **只能调用后端 `/app/**`**。统一用 `src/api/request.js` 的 `request(url, { method, data })`，不得直接调用 `uni.request`。
- 返回值为后端统一响应 `{code, msg, data}`；`code` 不是 200 时 `request` 抛出 `Error(msg)`，页面用 `uni.showToast` 或页内提示展示 `msg`。
- 身份：匿名访客令牌由 `request` 自动取得并放在请求头 `X-Visitor-Token`；访客失效（`code` 401）时自动换新令牌重试一次。**不得在请求里传用户 ID、访客 ID**，后端只认令牌。
- 写操作需要防重复提交的（如创建测评），前端生成 `requestId`（UUID）并在重试时复用。
- 后端地址：H5 与 C 端页面同源（Nginx 只代理 `/app/**`），`VITE_API_BASE` 留空；小程序用 `VITE_MP_API_BASE`（后台配置的 request 合法域名，HTTPS、已备案）。

## 4. 渠道码与内容编号

- 入口链接带 `ch`（渠道码）、`ct`（内容编号），如 `https://m.<域名>/?ch=xhs&ct=note123`；也接受 `channel`、`content`。格式：字母、数字、`_`、`-`，最多 32 位，格式不对忽略。
- 首次进入的渠道只记一次，用于创建访客；最近一次带渠道码的进入用于测评等转化动作（`utils/channel.js` 的 `firstTouch` / `lastTouch`）。
- 新页面需要透传渠道时，从 `lastTouch(storage)` 取，不要重新解析地址。
- 小程序码：`scene` 参数写成 `ch=xhs&ct=n1`（最多 32 个字符），`pickCodes` 会解码后读取；地址参数优先于 scene。

## 4.1 隐私同意

- 同意页的摘要取问卷定义的 `consent.summary`，全文取 `GET /app/policy/{code}`（`components/PolicyText.vue` 按纯文本段落展示，不渲染 HTML）；协议为草案时显示“草案”标识。
- 创建测评时回传同意的 `policyVersion`；后端发现版本已更新会拒绝，页面重新加载协议让学生再次阅读。
- 不同意时不调用任何写接口，返回落地页。

## 5. 展示与合规

- 学生、家长填写或后端返回的文本一律用 `{{ }}` 文本插值，**禁止 `v-html`**（后端只拒绝类似 HTML 标签的输入，不做转义）。
- 学生只看到冲 / 稳 / 保分档，**不展示录取概率百分比、综合分、参考线**（后端 `/app/**` 也不返回）。
- AI 生成的内容（报告解读等）标明“AI 生成”。
- 未成年人：美高、美本学段以家长为账号主体；营销、分享奖励类内容只面向成年人；分享卡默认不含孩子的姓名、学校、照片。
- 隐私：手机号等敏感信息只在用户明确同意的步骤收集，且单独说明用途。

## 6. 代码风格

- Vue 3 `<script setup>`；函数写中文注释说明用途；变量、函数小驼峰。
- 字符串用双引号，不写分号（与管理后台一致）。
- 页面样式 `scoped`；颜色、圆角用 `uni.scss` 变量。
- 不硬编码可配置的选项（学段名称、国家等以接口返回为准）。
